# Cloudflare

Para qualquer tarefa deste projeto que envolva Cloudflare — deploy, Workers, Pages,
R2, variáveis, logs ou configurações — use as skills e a integração Cloudflare
disponíveis antes de recorrer a instruções manuais. Antes de publicar ou alterar
recursos remotos, valide a configuração e peça confirmação quando a alteração for
relevante ou irreversível.
